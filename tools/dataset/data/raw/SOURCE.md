# Source

Goethe-Zertifikat A1 and A2 Wortlisten, as parsed by
https://github.com/ilkermeliksitki/goethe-institute-wordlist (commit fetched 2026-08-24).

Format: TSV, one file per initial letter, three columns —

    lemma-with-article-and-plural <TAB> German example sentence <TAB> English translation

The upstream repo also carries the official Goethe PDFs it was parsed from
(`pdf-files/a1.pdf`, `a2.pdf`); those are the audit trail for any row in question.

Goethe-Institut material. Personal single-user build; not redistributed.
